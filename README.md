# SecureOps Lab: A Simulated Security Operations Center

**Author:** Ige Abdulmuiz Kehinde

## 📖 Project Overview

I built **SecureOps Lab**, a simulated Security Operations Center (SOC) environment to apply the practical cybersecurity concepts I learned through the **Google Cybersecurity Professional Certificate** and hands-on lab work.

The project was designed to move beyond isolated exercises and demonstrate how security events can be **generated, detected, investigated, contained, and documented** within a controlled virtual environment.

The lab covers the following workflow:

**Plan → Build → Generate Threats → Detect → Investigate → Respond → Automate → Document**

## 🎯 Project Objectives

* **Practical Application:** Apply cybersecurity concepts through hands-on Linux, networking, SIEM, and command-line activities.
* **Detection & Investigation:** Generate realistic security events and investigate the resulting logs and alerts.
* **Incident Response:** Practice identifying Indicators of Compromise (IoCs), analysing attack activity, and applying containment measures.
* **Security Automation:** Build simple scripts to support log analysis and automated firewall-based containment.
* **Documentation:** Produce structured incident reports based on simulated security events.

## 🏗️ Lab Architecture

The lab was implemented using **Oracle VirtualBox** with security test traffic passing through an isolated Host-Only network:

**Host-Only Network:** `192.168.56.0/24`

### Environment

| System                    | Role                       | Purpose                                                                 |
| ------------------------- | -------------------------- | ----------------------------------------------------------------------- |
| **Wazuh Manager v4.14.4** | SIEM / Security Monitoring | Centralized log collection, alerting, FIM and security event analysis   |
| **Ubuntu Server 16.04**   | Monitored Endpoint         | Authentication monitoring, file integrity monitoring and log generation |
| **Kali Linux**            | Attacker Simulation        | Reconnaissance, scanning and controlled attack simulation               |
| **Python 3**              | Security Automation        | Log parsing and malicious IP extraction                                 |
| **Bash / UFW**            | Containment                | Automated firewall blocking of identified IP addresses                  |
| **Wireshark / Nmap**      | Network Analysis           | Packet inspection, reconnaissance and network activity analysis         |

## 🚨 Simulated Incident Scenarios

### INC-001 — SSH Brute Force Attack

Simulated repeated SSH authentication failures against the monitored Ubuntu endpoint.

**Focus:** Authentication log analysis, Wazuh detection and manual containment.

### INC-002 — Network Reconnaissance

Performed controlled Nmap reconnaissance against the lab environment and analysed the resulting network activity.

**Focus:** Reconnaissance detection, port scanning and service enumeration.

### INC-003 — File Integrity Violation

Modified monitored files on the Ubuntu endpoint to simulate unauthorized changes.

**Focus:** Wazuh File Integrity Monitoring (FIM/Syscheck) and alert investigation.

### INC-004 — Threat Investigation

Performed a deeper investigation of collected security telemetry using Wazuh dashboard queries and Linux command-line log analysis.

**Focus:** Event correlation, investigation and evidence collection.

### INC-005 — Automated Containment

Built a workflow that extracts suspicious IP addresses from authentication logs and applies UFW firewall rules to block them.

**Focus:** Python automation, regular expressions, Bash scripting and firewall-based containment.

## ⚠️ Lab Scope & Limitations

This is a **simulated SOC environment built for learning and portfolio demonstration**. The attacks are performed only within the controlled virtual lab.

The environment does not represent a production SOC and does not attempt to reproduce the scale, tooling, or operational processes of an enterprise security team.
